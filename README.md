# Копия сайта roskon.org (ООО Фирма «РОСКОН»)

Полная копия старого сайта http://roskon.org/, снята 29.10.2026, пока сайт был включён.

## Что внутри
- 14 страниц HTML как на сайте: тексты, меню, ссылки между страницами.
- Все картинки сайта (папка `i/`), стили `styles.css`, скрипт `scripts/`, иконка `favicon.ico`.
- `ВЕСЬ_ТЕКСТ_САЙТА.txt`: текст всех страниц одним файлом в UTF-8.

## Как открыть
- В интернете: https://arturleto.github.io/roskon-original/
- На компьютере: открыть `index.html` в браузере. Работает без интернета.

Оригинал был в кодировке windows-1251. Страницы переведены в UTF-8, чтобы русский текст правильно показывался на GitHub. Текст и вёрстка не менялись.
Файлы точно как скачано лежат в первом коммите истории.
