# Копия сайта roskon.org (ООО Фирма «РОСКОН»)

Полная копия старого сайта http://roskon.org/, снята 29.10.2026, пока сайт был включён.

## Что внутри
- 14 страниц HTML как на сайте: тексты, меню, ссылки между страницами.
- Все картинки сайта (папка `i/`), стили `styles.css`, скрипт `scripts/`, иконка `favicon.ico`.
- `ВЕСЬ_ТЕКСТ_САЙТА.txt`: текст всех страниц одним файлом в UTF-8.

## Как открыть
Открыть `index.html` в браузере. Всё работает без интернета.

Страницы сайта в кодировке windows-1251, как в оригинале. Браузер показывает их нормально.
На GitHub код страниц может выглядеть кракозябрами, это нормально. Текст читать в `ВЕСЬ_ТЕКСТ_САЙТА.txt`.
